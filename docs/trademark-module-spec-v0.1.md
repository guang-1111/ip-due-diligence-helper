# 商标网核模块执行规格 v0.1

## 1. 模块定位

商标网核模块是知识产权网络核查助手 MVP 中第一批真正自动执行的模块。它以权利人名称为主输入，在国家商标局商标查询网站中查询该权利人名下公开商标信息，保存查询目录页和各项详情页，并生成日志和核对结果。

本模块采用半自动化策略：

- 使用可见浏览器；
- 使用者自行登录；
- 程序接管浏览器执行重复操作；
- 遇到验证码、登录失效、页面异常时暂停；
- 不绕过验证码；
- 不做高频并发抓取；
- 不默认删除任何已生成底稿。

## 2. 目标网站

第一版目标网站：

```text
国家商标局商标查询
http://wcjs.sbj.cnipa.gov.cn/
```

默认打开入口：

```text
https://sbj.cnipa.gov.cn/sbj/index.html
```

历史上可见的深层入口包括：

```text
http://wcjs.sbj.cnipa.gov.cn/sgtmi
```

但该深层入口可能被网站防护系统阻断。第一版程序不得默认直达 `/sgtmi`，应先打开商标局官网，由使用者按真实人工流程进入商标查询系统。模块仍应允许在配置中维护入口 URL。

## 3. 输入与输出

### 3.1 输入

模块主输入为项目中的 `subjects` 清单：

| 字段 | 必填 | 说明 |
|---|---:|---|
| subject_index | 是 | 主体序号 |
| subject_name | 是 | 权利人名称 |
| subject_level | 否 | 发行人、子公司、孙公司等 |
| note | 否 | 备注 |

第一版主流程按权利人名称查询。

旧 demo 中的“按注册号查询”能力可以保留为高级模式，但不是 MVP 主路径。

### 3.2 输出

每个权利人至少可能产生：

- 商标目录页 PDF；
- 商标无结果页 PDF 或无结果日志；
- 商标详情页 PDF；
- 异常页 PDF；
- `capture_records.csv` 记录；
- 运行日志；
- 核对报告条目。

## 4. 前置条件

运行前必须满足：

1. 项目已创建；
2. 权利人清单已确认；
3. 目录结构和文件命名规则已配置；
4. 用户已选择启用商标模块；
5. 可见浏览器已打开；
6. 用户已登录商标查询网站；
7. 浏览器停留在商标查询相关页面；
8. 程序可以连接浏览器；
9. 当前页面不处于验证码、登录页或明显错误页。

如果任一条件不满足，模块不得开始批量执行。

## 5. 浏览器连接

### 5.1 推荐模式

第一版推荐连接已有浏览器。

用户操作：

```text
打开浏览器
进入商标查询网站
完成登录
停留在商标综合查询页面
点击工具中的“连接浏览器”
```

程序操作：

```text
连接本机浏览器调试端口
枚举打开的页面
识别商标查询页面
检查页面状态
显示当前连接页面标题和 URL
等待用户确认开始
```

### 5.2 页面选择规则

如果浏览器中有多个页面，优先选择：

1. URL 包含 `wcjs.sbj.cnipa.gov.cn` 的页面；
2. 页面标题包含“商标”的页面；
3. 页面正文包含“商标综合查询”“商标查询”“注册号”“申请人”等关键词的页面。

如果无法唯一识别，需要让用户手动选择页面。

## 6. 页面状态识别

模块需要识别下列页面状态：

| 状态 | 说明 | 处理 |
|---|---|---|
| ready_search | 可输入查询条件 | 继续 |
| ready_result | 已显示查询结果目录页 | 可保存目录页 |
| ready_detail | 已显示详情页 | 可保存详情页 |
| no_result | 查询无结果 | 保存无结果页或记录 |
| captcha | 验证码/滑块/安全验证 | 暂停 |
| login | 登录页或 SSO 页面 | 暂停 |
| loading | 加载中 | 等待 |
| error | 403/404/系统异常/页面崩溃 | 重试或暂停 |
| unknown | 无法判断 | 暂停或提示人工确认 |

### 6.1 验证码识别关键词

正文或可见文本包含以下关键词时，判定为 `captcha` 或疑似验证码：

```text
验证码
滑块
安全验证
请完成验证
行为验证
机器人
```

### 6.2 登录失效识别关键词

正文、标题或 URL 包含以下关键词时，判定为 `login` 或疑似登录失效：

```text
登录
统一身份认证
SSO
账号
密码
请先登录
```

### 6.3 加载中识别关键词

正文包含以下关键词且关键字段尚未出现时，判定为 `loading`：

```text
加载中
正在加载
请稍候
查询中
数据加载
```

## 7. 轻量页面就绪闸门

每次保存 PDF 前，必须通过“轻量页面就绪闸门”。闸门的目标是在截图速度和底稿质量之间取得平衡：默认只做 3 个关键检查，不做复杂、多轮、耗时的深度验证。

默认闸门原则：

```text
异常页检查
→ 关键字段检查
→ 一次稳定性检查
→ 通过后保存 PDF
```

不能仅依赖固定等待时间截图，也不能在页面状态不明时批量保存。

### 7.1 检查一：异常页检查

异常页检查用于快速排除明显不能作为底稿的页面。该检查成本低，必须默认执行。

如果页面标题、URL 或正文包含以下内容，判定为异常或疑似异常：

```text
验证码
滑块
安全验证
请完成验证
登录
统一身份认证
账号
密码
403
404
系统异常
服务繁忙
请求失败
加载中
正在加载
查询中
```

处理规则：

| 状态 | 处理 |
|---|---|
| 验证码/登录页 | 立即暂停，等待人工处理 |
| 403/404/系统异常 | 重试 1 次，仍失败则暂停 |
| 加载中/查询中 | 进入补等流程，不立即截图 |

### 7.2 检查二：关键字段检查

关键字段检查用于确认页面已经出现本步骤应有的核心内容。

目录页通过条件：出现以下任一类内容即可。

有结果目录页锚点：

```text
注册号
申请号
商标名称
申请人
权利人
国际分类
分类号
详情
查看
```

无结果目录页锚点：

```text
暂无数据
无结果
未查询到
没有符合条件
查询结果为空
```

详情页通过条件：

- 如果已知目标注册号/申请号，优先要求页面文本包含该号码；
- 如果无法取得目标注册号，则至少出现以下字段中的任意两个：

```text
商标名称
注册号
申请号
申请人
权利人
国际分类
分类号
专用权期限
法律状态
流程状态
```

如果关键字段检查失败，不应截图。系统进入补等流程。

### 7.3 检查三：一次稳定性检查

稳定性检查用于避免页面刚开始渲染就截图。

默认只做一次轻量检查：

```text
读取页面文本长度和结果行数量
等待 800ms-1000ms
再次读取页面文本长度和结果行数量
如果变化幅度不大，视为稳定
如果变化很大，额外等待 2 秒后再检查一次
```

建议稳定性判断：

| 指标 | 默认判断 |
|---|---|
| 文本长度变化 | 小于 20% 视为稳定 |
| 结果行数量变化 | 无明显变化视为稳定 |
| 关键字段 | 第二次读取仍存在 |

如果额外检查后仍不稳定，系统提示：

```text
页面疑似仍在加载，暂不建议保存。
你可以选择：继续等待、仍然保存、跳过当前项、手动处理后继续。
```

### 7.4 默认等待策略

默认不做长时间等待。每个页面先给一个基础等待，再执行轻量闸门。

| 场景 | 基础等待 | 最多补等 | 失败后 |
|---|---:|---:|---|
| 目录页 | 2 秒 | 8 秒 | 提示用户 |
| 详情页 | 1.5 秒 | 6 秒 | 记录/提示 |
| 慢速模式目录页 | 4 秒 | 20 秒 | 提示用户 |
| 慢速模式详情页 | 3 秒 | 15 秒 | 提示用户 |

### 7.5 慢速和手动模式

页面就绪闸门支持三种模式：

| 模式 | 说明 |
|---|---|
| standard | 默认模式，执行三项轻量检查 |
| slow | 延长基础等待和补等时间，适合政府网站卡顿 |
| manual | 检测通过后仍询问用户是否保存 |

复杂检查，例如多轮稳定、DOM 高度变化、网络空闲时间、OCR 检测，不作为默认流程；仅作为后续严格验证或调试模式预留。

### 7.6 连续失败保护

为避免大批量生成无效 PDF，模块必须设置连续失败保护。

建议阈值：

| 条件 | 动作 |
|---|---|
| 连续 3 次页面就绪失败 | 暂停整个任务 |
| 连续 3 个 PDF 验证失败 | 暂停整个任务 |
| 同一主体连续 2 个详情页失败 | 暂停当前主体，提示人工确认 |

暂停提示：

```text
检测到连续多次页面未加载完成或截图验证失败。
为避免批量生成无效底稿，任务已暂停。
请检查网络、登录状态或网站是否异常。
```

### 7.7 就绪检查日志

每次截图前应记录轻量就绪检查结果。第一版可以写入 `ready-check-log.jsonl`。

字段示例：

```json
{
  "time": "2026-07-07T16:20:00+08:00",
  "subject": "示例科技（北京）有限公司",
  "pageType": "catalog",
  "url": "https://...",
  "mode": "standard",
  "decision": "save_pdf",
  "hasAbnormalText": false,
  "keyFieldPassed": true,
  "stabilityPassed": true,
  "textLengthBefore": 3200,
  "textLengthAfter": 3260,
  "resultRowCountBefore": 12,
  "resultRowCountAfter": 12,
  "message": "页面通过轻量就绪闸门"
}
```

就绪检查日志用于调试，不替代 `capture_records.csv`。
## 8. 查询流程

### 8.1 单个权利人流程

对每一个权利人执行：

```text
进入或恢复商标查询页
检查页面状态
输入权利人名称
提交查询
等待目录页就绪
判断有结果/无结果/异常
保存目录页 PDF
解析目录页结果列表
逐项进入详情页
等待详情页就绪
保存详情页 PDF
返回目录页
继续下一项
写入主体完成日志
```

### 8.2 查询入口定位

程序应尽量定位“申请人/权利人/商标申请人”相关查询输入框，而不是注册号输入框。

候选标签或占位文本：

```text
申请人
申请人名称
权利人
商标申请人
申请/注册人
申请人中文名称
```

如果页面只暴露综合查询框，应记录查询方式为 `mixed_search`。

### 8.3 输入规则

输入权利人名称时：

- 先清空原输入；
- 输入完整权利人名称；
- 不自动改写主体名称；
- 不自动补全公司后缀；
- 不把简称扩展为猜测的完整名；
- 查询前记录原始权利人名称。

### 8.4 提交查询

优先点击页面上的查询按钮。候选按钮文本：

```text
查询
检索
搜索
开始查询
```

如果点击后页面未变化，允许尝试 Enter 提交一次。

提交后进入页面就绪等待流程。

## 9. 目录页处理

### 9.1 目录页定义

目录页是按权利人名称查询后出现的结果列表页。它用于证明该权利人名下公开显示的商标概览。

### 9.2 目录页保存时机

满足目录页就绪条件后立即保存目录页 PDF。

目录页文件名按项目配置生成，默认：

```text
{权利人}_商标目录页.pdf
```

如果无结果，默认：

```text
{权利人}_商标无结果页.pdf
```

### 9.3 无结果处理

如果页面明确显示无结果：

1. 保存无结果页 PDF，前提是页面可打印且内容完整；
2. 写入 `capture_records.csv`；
3. `page_type` 记为 `no_result`；
4. `status` 记为 `success` 或 `manual_review`，视页面明确程度而定；
5. 不进入详情页流程。

如果页面无法确认是否无结果，应标记为 `manual_review`。

### 9.4 目录页结果解析

程序应从目录页尽量提取：

| 字段 | 是否必须 | 用途 |
|---|---:|---|
| right_no | 是 | 详情页命名、核对 |
| right_name | 否 | 报告展示 |
| class_no | 否 | 多分类命名 |
| applicant | 否 | 权利人匹配 |
| legal_status | 否 | 报告展示 |
| detail_link | 是 | 进入详情页 |

如果无法解析出 `detail_link`，但目录页已保存，应记录 `目录页已保存，详情入口识别失败`，并把该主体列入人工复核。

## 10. 详情页处理

### 10.1 详情页进入方式

从目录页逐项点击详情入口。候选入口包括：

```text
详情
查看
查看详情
注册号链接
商标名称链接
结果行可点击区域
```

如果点击后打开新标签页，应在新标签页处理详情页，保存后关闭并回到目录页。

如果在当前页跳转，应保存后返回目录页，并确认目录页状态仍可继续。

### 10.2 详情页保存时机

满足详情页就绪条件后保存 PDF。

普通详情页默认文件名：

```text
{注册号}_详情页.pdf
```

同一注册号对应多个分类号时：

```text
{注册号}（{分类号}）_详情页.pdf
```

如果缺少注册号但能识别商标名称：

```text
{序号}_{商标名称}_详情页.pdf
```

如果注册号和商标名称都无法识别：

```text
{序号}_未知商标详情页.pdf
```

无法识别关键字段的详情页必须标记为 `manual_review`。

### 10.3 多页详情

如果详情页存在分页、展开项或“下一页”：

- 第一版可以只保存默认详情页；
- 如果能稳定识别分页，保存为：

```text
{注册号}_详情页.pdf
{注册号}_详情页_第2页.pdf
```

是否自动处理多页详情应写入配置。

第一版默认：

```text
保存默认详情页；发现多页时记录提醒，不强制自动翻页。
```

## 11. PDF 生成

### 11.1 基本要求

PDF 由程序直接生成，不调用系统打印弹窗。

PDF 必须包含：

- 网页主体内容；
- 核查日期；
- 页面 URL；
- 页码。

### 11.2 页脚模板

默认页脚：

```text
核查日期：{核查日期}    网址：{页面URL}    第 {pageNumber} 页 / 共 {totalPages} 页
```

视觉要求：

- 字号 8px-10px；
- 灰色；
- 不遮挡网页主体内容；
- 位置接近浏览器打印页脚；
- URL 过长时允许截断，但完整 URL 必须保留在日志中。

### 11.3 PDF 保存前动作

保存前应：

1. 记录当前 URL；
2. 记录当前页面标题；
3. 运行页面就绪检查；
4. 如果就绪，生成 PDF；
5. 如果未就绪，进入等待或人工确认。

### 11.4 文件冲突

按项目配置处理：

| 策略 | 行为 |
|---|---|
| skip | 文件存在则跳过 |
| overwrite | 覆盖 |
| append | 自动追加序号 |

第一版默认 `skip`。

## 12. PDF 验证

PDF 验证由用户选择开启，默认关闭。

### 12.1 基础验证

基础验证步骤：

1. 保存 PDF；
2. 提取 PDF 文本；
3. 检查文本长度；
4. 检查主体名称或权利号；
5. 检查异常关键词；
6. 写入验证结果。

### 12.2 目录页验证规则

目录页验证通过条件：

- PDF 文本长度不低于阈值；
- 包含权利人名称，或包含查询条件；
- 包含结果列表关键词，或明确无结果关键词；
- 不包含登录页、验证码页、错误页关键词。

### 12.3 详情页验证规则

详情页验证通过条件：

- PDF 文本长度不低于阈值；
- 如果已知注册号，PDF 文本应包含注册号；
- 或包含商标名称、权利人、分类号、法律状态等至少两类详情字段；
- 不包含登录页、验证码页、错误页关键词。

### 12.4 验证失败处理

验证失败时：

- 不自动删除 PDF；
- 在日志中标记 `validation_status=failed`；
- 弹出提示让用户选择：
  - 重新截图；
  - 保留并标记人工复核；
  - 跳过；
  - 手动处理后继续。

## 13. 异常处理

### 13.1 异常与处理策略

| 异常 | 默认处理 |
|---|---|
| 验证码 | 暂停，等待人工处理 |
| 登录失效 | 暂停，等待重新登录 |
| 查询页无法打开 | 重试 1 次，失败后暂停 |
| 目录页加载超时 | 提示继续等待/仍然保存/跳过/手动处理 |
| 详情页加载超时 | 重试 1 次，失败后记录并继续下一项 |
| 详情入口识别失败 | 保存目录页，标记人工复核 |
| 详情页字段识别失败 | 保存详情页，标记人工复核 |
| 文件保存失败 | 重试 1 次，失败后记录 |
| 浏览器连接断开 | 暂停，提示重新连接 |

### 13.2 暂停提示

暂停时界面显示：

```text
商标模块已暂停。
主体：{权利人}
当前步骤：{步骤}
原因：{原因}
请在浏览器中处理后点击继续，或选择跳过当前主体。
```

### 13.3 用户操作

暂停时用户可以：

- 继续；
- 重试当前步骤；
- 跳过当前详情项；
- 跳过当前主体；
- 停止任务；
- 打开输出文件夹。

## 16. 核对逻辑

### 16.1 权利人级核对

每个权利人应有以下结果之一：

- 有目录页且有详情页；
- 有目录页但无结果；
- 有目录页但详情识别失败，需要人工复核；
- 查询失败；
- 用户跳过。

### 16.2 详情页核对

如果目录页成功解析出 N 个详情项，则核对：

- 是否保存 N 个详情页；
- 是否存在保存失败；
- 是否存在验证失败；
- 是否存在重复注册号多分类未区分命名。

### 16.3 多分类号核对

同一注册号出现多个分类号时，必须按分类号分别保存详情页。

示例：

```text
10000000（44）_详情页.pdf
10000000（35）_详情页.pdf
```

不能用：

```text
10000000_详情页.pdf
```

抵充多个分类号。

## 18. 第一版开发边界

第一版必须做：

- 连接已登录浏览器；
- 识别商标查询页面；
- 按权利人名称查询；
- 等待目录页就绪；
- 保存目录页 PDF；
- 识别无结果页；
- 尝试解析详情入口；
- 保存详情页 PDF；
- 可选 PDF 基础验证；
- 轻量页面就绪闸门；
- 连续失败保护；
- 异常暂停；
- 日志写入；
- 核对报告数据输出。

第一版可以暂缓：

- 完整 OCR 验证；
- 多页详情自动展开；
- 复杂筛选条件；
- 自动翻目录页分页；
- 按注册号批量补截图的界面化；
- 与律师工作报告附件自动比对。

## 19. 验收标准

商标模块可验收条件：

- 用户可以连接已登录浏览器；
- 系统能识别当前是否为商标查询页面；
- 系统能按至少 1 个权利人名称发起查询；
- 系统能在目录页加载完成后保存 PDF；
- PDF 页脚包含日期、URL 和页码；
- 系统不会在明显加载中页面立即保存；
- 截图前必须通过轻量页面就绪闸门；
- 连续页面就绪失败达到阈值时必须暂停任务；
- 就绪检查结果应写入 `ready-check-log.jsonl`；
- 系统能识别无结果页面并记录；
- 系统能进入至少 1 个详情页并保存 PDF；
- 系统能把目录页和详情页记录写入 `capture_records.csv`；
- 开启基础验证时，验证结果能写入日志；
- 遇到验证码或登录失效时会暂停；
- 不会自动删除用户已保存的 PDF；
- 运行结束后能生成商标模块核对数据。
